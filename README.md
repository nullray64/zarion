<blockquote align="center">

## Основные возможности

* **Управление персоналом:** Подача и рассмотрение заявок на роли `Support` и `Creative` через интерактивные селекторы и модальные окна.
* **Модерация:** Выдача варнов (автобан при 3/3), мутов (таймаутов) и банов с полной фиксацией действий.
* **Логирование:** Отслеживание входов/выходов пользователей, смены никнеймов, редактирования и удаления сообщений, а также переходов по голосовым каналам в `#logs`.
* **Экономика активности:** Начисление монетизации за сообщения и время в voice-каналах. Поддержка переводов (с комиссией 2%), покупки кастомных ролей и создания личных голосовых комнат.
* **Интерактивы:** Динамическая спавн-игра «Поймай утку» при всплесках активности в чате и текстовая игра в «Города».

## Технологический стек

* **Language:** Python 3.12+
* **Framework:** `discord.py` (v2.3+)
* **Database:** SQLite (`aiosqlite`)
* **Process Manager:** `systemd` (Ubuntu 26.04)

## Быстрый старт

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/your-repo/zarion-bot.git /opt/zarion-bot
   cd /opt/zarion-bot
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

3. **Настройте конфигурацию:**
   Укажите токен бота, ID ролей, категорий и каналов в файле `config.py`.

4. **Запустите сервис:**
   ```bash
   sudo systemctl enable --now zarion-bot
   ```
